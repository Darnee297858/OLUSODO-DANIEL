# 🚀 Daniel Olusodo — Flagship Portfolio Web Application

An ultra-sophisticated, interactive personal portfolio web application built for **Daniel Olusodo**, a 400-level Computer Engineering student showcasing full-stack engineering skills, deployed applications, and social channels.

---

## 🌟 Key Features

- ⚡ **Cyber Boot Sequence:** Interactive terminal startup animation on application launch.
- 🎨 **Modern Dark Glassmorphic Design:** Styled with Tailwind CSS, custom blur filters, and glowing accents.
- 📱 **All 4 Deployed Projects Featured:**
  1. **NaijaGrid** ([naijagrid.vercel.app](https://naijagrid.vercel.app))
  2. **Aether Cloud** ([aethercloud.vercel.app](https://aethercloud.vercel.app))
  3. **Nexus Luxe Store** ([nexus-luxe-store-xi.vercel.app](https://nexus-luxe-store-xi.vercel.app))
  4. **NexusFlow Kanban** ([nexusflow-kanban.vercel.app](https://nexusflow-kanban.vercel.app))
- 🔍 **Interactive Live Viewport Modals:** Preview projects directly inside the application.
- 📄 **Built-in Resume / CV Modal:** Quick access to education, technical skills, and achievements.
- 🌐 **Complete Social & Contact Hub:** Direct channels for WhatsApp, Phone, Email, LinkedIn, X, GitHub, and Linktree.

---

## 🚀 Quick Setup & Local Run

1. Open VS Code.
2. Select **File > Open Folder...** and choose the extracted `daniel-olusodo-portfolio` folder.
3. Open `index.html` with **Live Server** or open directly in any browser!
